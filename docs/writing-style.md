# RFS.jp ライティングスタイル

## 基本方針

初心者向けの技術記事だが、教科書のような文章にはしない。
読者に話しかけるように書く。
文章には少し余白を持たせる。
技術的な正確性を最優先しながら、読み物としても楽しめる文章を目指す。

## 文体

- 丁寧語を基本とする
- フレンドリーだが馴れ馴れしくしない
- 上品さを保つ
- 読者を子ども扱いしない
- 「〜してください」の連続を避ける
- 一文を長くしすぎない
- 短い文章と少し長い文章を組み合わせる
- 適度に改行する

## 語り口

読者に直接説明するだけでなく、
ときどき問いかける。

例：

「では、なぜHTMLが必要なのかな。」
「少し不思議だよね。」
「実際に書いてみると、その理由がよく分かるんだ。」

## 比喩

技術を説明するために、
日常的な比喩を適度に使用する。
ただし、比喩を連続させない。
比喩そのものを面白くすることを目的にしない。

## ユーモア

控えめに使用する。

読者を笑わせようとしすぎない。

少しだけ肩の力が抜ける程度にする。

## 避ける表現

- 過度なテンション
- 「超重要！」
- 「絶対に覚えましょう！」
- 大げさな煽り

## 技術説明

文学的な導入を書いた後は、
具体的かつ正確に説明する。

コード例を出す。

コードの結果を説明する。

必要ならAIに質問するための質問文を提示する。

## 基本構成

1. 少し興味を引く導入
2. なぜこの技術が必要なのか
3. 技術の基本的な説明
4. まとめ

## ショートカットキー

3つのキーを同時に押す場合の表記例：［Ctrl］ + ［Shift］ + ［X］
メニューから選択する場合の表記例：［ファイル］-［開く］
