# RFS.jp 文体ガイド

## 基本

Web制作初心者に向けた文章。
フレンドリーだが、馴れ馴れしくしない。
上品で落ち着いた文章にする。
教科書のように説明しすぎない。
読者に話しかけるように書く。

## 文章

短い文章と長い文章を適度に組み合わせる。

一文を長くしすぎない。

段落は短めにする。

「です・ます」調。

断定しすぎない。

## 表現

必要に応じて日常的な比喩を使う。

ただし、比喩を多用しない。

少しだけユーモアを入れてもよい。

大げさな表現は避ける。

## 避ける

「超重要」
「絶対に覚えましょう」
「誰でも簡単」
「たった○分で」
「爆速」
「神ツール」

などの煽る表現。

過度なポエム表現。

過度に文学的な表現。

読者を初心者扱いしすぎる表現。
