3. HTML・CSS・JavaScriptの関係

	HTML
	構造を作る

	CSS
	見た目を整える

	JavaScript
	動きをつける

	という全体像。

	さらに、

	HTML
	 ↓
	CSS
	 ↓
	JavaScript

	という単純な依存関係だけではなく、

	HTML
	 ├── CSSで見た目を変更
	 └── JavaScriptで操作

	という関係も説明します。
	タグやプロパティには踏み込みません。
	それぞれの入門講座へ送ります。

4. AIを使ったWeb制作

	ここをこの講座の大きな柱にするとRFS.jpらしくなります。

	AIに何をしてもらえるか
	HTMLを書く
	CSSを書く
	JavaScriptを書く
	コードを説明してもらう
	エラーの原因を調べてもらう
	コードを修正してもらう
	コードを別の書き方に変えてもらう
	Web制作の疑問を質問する
	学習内容を整理してもらう
	AIに質問するときの基本
	何を作りたいのか伝える

	HTMLとCSSでボタンを作っています。

	スマートフォンでは横幅100%、
	PCでは200pxにしたいです。

	現在のコードは以下です。

	[コード]

	どこを変更すればよいですか？

	というような質問の作り方。

	「このJavaScriptを1行ずつ説明してください」
	「初心者向けに説明してください」

	ChromeのConsoleエラーも扱います。

	ただし、具体的なJavaScriptエラーの解説はJS講座へ。

8. Web制作の基本的な制作フロー

	ここはHTML/CSS/JS講座と重複しにくいです。

	企画
	 ↓
	デザイン
	 ↓
	HTML
	 ↓
	CSS
	 ↓
	JavaScript
	 ↓
	確認
	 ↓
	修正
	 ↓
	公開

	さらに、

	AIに相談
	 ↓
	コードを書く
	 ↓
	ブラウザで確認
	 ↓
	修正

	というAI時代の制作フローを加えます。
